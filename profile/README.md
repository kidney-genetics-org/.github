# kidney-genetics-org

Open tools for kidney-disease genetics: a curated, evidence-scored database of kidney-disease genes, and the Nephro Candidate Score for prioritizing candidate genes and variants in chronic kidney disease.

| Repository | Purpose |
|---|---|
| [kidney-genetics-db](https://github.com/kidney-genetics-org/kidney-genetics-db) | Kidney-Genetics Database: web app, API and read-only MCP server |
| [kidney-genetics-v1](https://github.com/kidney-genetics-org/kidney-genetics-v1) | Original Kidney-Genetics R pipeline |
| [nephro_candidate_score](https://github.com/kidney-genetics-org/nephro_candidate_score) | Nephro Candidate Score (NCS) for variant prioritization |
| [nc-scorer](https://github.com/kidney-genetics-org/nc-scorer) | Web tool for NCS candidate-gene assessment |

Database: [kidney-genetics.org](https://kidney-genetics.org/) · NC-Scorer: [nc-scorer.kidney-genetics.org](https://nc-scorer.kidney-genetics.org/) · Software DOI: [10.5281/zenodo.19316248](https://doi.org/10.5281/zenodo.19316248)
